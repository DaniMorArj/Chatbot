# chatbot-guiado

Servicio del chatbot (guiado, **sin coste de IA**) con registro central, panel interno y widget embebible.

Documentación completa en la carpeta [`Docs/`](../Docs/).

Arranque rápido (requiere PostgreSQL; ver [Docs/operaciones.md](../Docs/operaciones.md)):

```bash
pip install -r requirements.txt
python server.py
```

- Chat: http://localhost:3100/?tienda=demo-01
- Panel: http://localhost:3100/panel
